# GeoField 브래킷 비교기 (마지막 B · 2단계 첫 판)

10번 논문 **「다방향 하중을 받는 L자 브래킷에서 두 홀의 고정 조합이 최대 변위에 미치는 영향」**의 수치를 누구나 직접 비교할 수 있게 만든 교육용 애플리케이션입니다.

## 실행
- 온라인: https://t10-geofield-paper.vercel.app/app/
- 오프라인: 이 폴더의 `index.html`을 브라우저로 열기
- 로그인·설치·API 키 불필요

## 사용자가 할 일 3가지
1. 논문에서 분석한 하중 방향 `-Z`, `45°`, `-X` 중 하나를 선택합니다.
2. H1~H4 중 고정 홀 2개를 선택합니다. 2개를 초과하거나 부족하게 선택해도 화면이 멈추지 않습니다.
3. 선택 조합의 최대 변위(mm)를 6개 조합과 비교하고 기준/세분화 메시 결과를 전환합니다.

## 논문 근거
- 원문: https://github.com/dfdfewqk/10/blob/main/index.html
- 3.1절 기준 메시의 18조건 및 3.2절 세분화 메시의 18조건, 총 36개 수치를 코드에 보존했습니다.
- 연구 모델은 4홀 L자 브래킷, 50 N 정하중, 홀 내벽 완전 고정이라는 이상화된 조건입니다.
- 조사한 방향 모두 F(H3+H4)가 가장 작은 최대 변위를 보였으나, 메시 수렴이 검증되지 않았고 실제 체결물의 안전성을 입증하지 않습니다.
- 새로운 FEA 계산은 수행하지 않습니다.

## 입력 안전성
논문에 없는 하중 방향·메시·홀 조합의 URL 인자는 무시합니다. 세 번째 홀 선택 시 안내하고 해제할 때에는 결과 대신 안내를 출력합니다. 개인정보나 시크릿을 취급하지 않습니다.

## 테스트
ChatGPT에서 작성·실행한 Playwright/Chromium 자동 테스트 7개 통과(첫 화면, 사용자 행동, 논문 수치, 예외 처리, 모바일 가로 스크롤). 외부 배포 URL 실접속 검증은 별개입니다.

## 3단계: 공개 데이터 및 비밀값 점검 (BRB-C06, BRB-C07)

### 데이터 출처와 예시
- **데이터 분류:** 공개 연구 결과(개인정보가 아닌 결정론적 구조해석 수치)
- **출처:** 같은 저장소의 T10 논문 `index.html`, 3.1절과 3.2절
- **수록 위치:** `app/index.html`의 `PAPER_DATA` 상수
- **수록 범위:** 기준 메시 6개 고정 조합 × 3개 하중 방향 = 18개, 세분화 메시 18개, 총 36개 값
- **예시 입력 및 공개 수치:** 아래 값은 임의 생성하거나 익명화한 가상 결과가 아니라 논문 원문에 기록된 수치입니다.

| 예시 입력 | 기준 메시 최대 변위 | 세분화 메시 최대 변위 |
| --- | ---: | ---: |
| -Z, F(H3+H4) | 0.000844744 mm | 0.001336110 mm |
| -Z, C(H1+H4) | 0.000849355 mm | 0.001343246 mm |
| 45°, F(H3+H4) | 0.000604314 mm | 0.000951969 mm |

- 사용자의 이름, 연락처, 개인 응답, 계정 정보, 위치, 사진 또는 실제 부품 소유자의 정보는 데이터에 포함되지 않습니다.
- 조사 조건은 지정된 형상·50 N 하중·이상화 구속에 한정되며, 이 값으로 실제 구조물의 안전성을 판단할 수 없습니다.
